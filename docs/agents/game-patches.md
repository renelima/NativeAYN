# Game-specific patches

Every piece of code that runs for one game and not the others: the rewriter's patches of a game's builds (`dm/games/<id>/patches.py`, keyed by NSO build ID: [rewriter](../reference/rewriter.md)), the host's rows keyed by a game's build ID, the SDK cuts of the Nintendo SDK builds the games ship, translator rules keyed by one shader's code, and the profile keys that switch host behaviour. Each patch's reason is the one in its source; why it is needed, and what was measured, is in the game's note. Each patch states its binding: what it depends on now, the loosest it could depend on (its goal), its purpose and why ([Binding](#binding)); the [gaps](#gaps) are the work list. Offsets are from the module's start. Generated by `dm/tools/docs_patches.py` from those sources (a patch file's `BINDING`; the host rows', translator rules' and profile switches' entries in `docs_patches.py`): change the source, then run it.

## Binding

A patch's binding is what its correctness is anchored to, from the loosest. A patch is good design when its binding is the loosest that is correct (AGENTS.md prefers general fixes); the rules are in GitHub issue #635.

| Binding | Anchored to | Found by | Survives |
|---|---|---|---|
| `host` | Horizon / NVN / Vulkan semantics | nothing in the binary | every game and update |
| `sdk` | Nintendo SDK code (the `sdk` module) | a symbol, or a fingerprint of a reviewed SDK implementation | any game shipping that implementation |
| `engine` | middleware code: Unreal, Unity, Snowdrop, KTGL, sead, PhysX | a registered name, a string, or a fingerprint per engine version | any game on that engine version |
| `game` | the game's own code, or its profile's data | a function fingerprint (`MATCH_CUTS`), or a profile key | the game's updates that keep the function |
| `build` | fixed offsets | the NSO build ID | nothing: redone for every update |

- Status: **at goal** (the binding now is the goal), **gap** (it could be looser: the work list), **blocked** (a gap with the reason it cannot close yet), **kept** (a gap left open on purpose, with the decision) or **unreviewed** (a game's own build-bound patch whose goal nobody has judged yet, which a bring-up may leave rather than guess).
- Locators fail closed: a patch that finds its place in the binary (a function fingerprint, a registered name, a string) applies only where it finds exactly one match with its assumptions checked, and changes nothing otherwise, with a red line where it was expected to match (a profile's own `MATCH_CUTS`, a host search) and a plain one where a module may not need it (an SDK-wide rule). That is what makes a looser binding safe on builds nobody has seen ([function-matched cuts](../reference/rewriter.md#function-matched-cuts-for-unregistered-builds)).
- Evidence: **checked** (what was checked on game files, and when) or **judgement** (the goal is reasoned from the code and notes, not checked on game files).
- Purposes: address space, memory, race, frame rate, power, rendering, shaders, runtime.
